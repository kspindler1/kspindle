Live source integration

Data connectors

The agent reaches the Apollo Studio workflow, Veeva Vault, and SharePoint through a companion MCP server that runs locally — credentials never live in this browser page.

How this works

Dashboard ⇄ local MCP server ⇄ Apollo Studio agent / Veeva Vault / SharePoint
This dashboard cannot safely hold Vault, SharePoint, or Apollo credentials — all three require server-side auth. Instead, a small Node.js MCP server (in mcp-server/) holds them and exposes: (1) MCP tools an agent/MCP client can call, and (2) a local status API this page polls below.
